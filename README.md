# Amazon Web Page Clone (Desktop Edition)

A pixel-accurate front-end clone of the **Amazon** desktop homepage, designed to replicate the classic layout, navigation, and visual structure of the original platform. 

##  Features
* **Classic Navigation Header:** Replicates Amazon's signature top bar, including the logo, delivery location selector, global search bar, language switcher, account menus, and cart summary.
* **Hero Banner Section:** Features promotional landing banners and category shortcuts.
* **Structured Product Grid:** Cleanly organized product cards displaying item categories, promotional images, pricing, and customer ratings.
* **Comprehensive Footer:** Features multi-column customer service links, help resources, and a copyright notice.

## 🛠️ Tech Stack
* **HTML5:** Semantic document structure.
* **CSS3:** Styling, custom layouts, and precise positioning.

## 📂 Project Structure
- `index.html` - Main landing page markup
- `style.css` - Custom styling and fixed desktop layout rules
- `/images` - Asset files, brand logos, and product placeholders

## 💡 Purpose
Built as a front-end practice project to master block-level elements, component positioning using margins and padding, and styling accuracy based on a real-world e-commerce interface.
